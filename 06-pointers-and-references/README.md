# 06 — Pointers and References

## Learning goals
- Understand addresses, indirection, pointer safety, and C++ references.

## Core concepts
A pointer stores an address. Dereference only valid pointers to live objects. Avoid dangling pointers; references in C++ alias an existing object.

## Example / practice prompt
C++: int value=42; int* p=&value; std::cout << *p;

## Exercises
1. Swap two integers using C pointers
2. modify a value through a C++ reference
3. explain null and dangling pointers.
