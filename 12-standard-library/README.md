# 12 — C++ Standard Library

## Learning goals
- Choose containers and use algorithms and iterators.

## Core concepts
Use vector for resizable sequences, array for fixed sequences, map for ordered key/value pairs, and unordered_map for hash-based lookup. Algorithms express intent clearly.

## Example / practice prompt
C++: std::vector<int> v{7,2,9}; std::sort(v.begin(),v.end());

## Exercises
1. Count word frequency
2. remove duplicates
3. sort records
4. compare vector, list, map, and unordered_map.
