# Contributing

Contributions that improve clarity, correctness, portability, or practice value are welcome.

- Keep lessons beginner-friendly and organized by topic folder.
- Label examples as C or C++ and state the relevant language standard.
- Keep examples small, compilable, and portable where possible.
- Include exercises that test understanding rather than memorization.
- Verify commands and expected behavior before submitting changes.
- Prefer safe practices and explain common pitfalls.

For substantial changes, open an issue first to discuss the proposed structure.
